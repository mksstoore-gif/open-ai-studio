# SweepX Mobile Arabic

تطبيق أندرويد يفتح منصة X داخل WebView ويضيف لوحة عربية لتنظيف منشورات الحساب من واجهة X نفسها.

## الخصوصية
- تسجيل الدخول يتم داخل x.com في التطبيق.
- لا ينسخ التطبيق auth_token أو ct0 ولا يرسل جلسة الحساب إلى خادم وسيط.
- لا يبدأ أي حذف تلقائيًا.
- قبل بدء التنظيف يظهر تأكيد للمستخدم.
- زر إيقاف متاح أثناء الجولة.

## ملاحظة
يعتمد التنفيذ على عناصر واجهة X، لذلك قد تحتاج المحددات إلى تحديث إذا غيرت X تصميم الموقع.
